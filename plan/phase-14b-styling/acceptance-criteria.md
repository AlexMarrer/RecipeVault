# Acceptance Criteria – Phase 14b

- Alle Seiten wirken optisch zusammengehörig (Farben, Abstände, Typo, Buttons konsistent).
- Eigene Komponenten verwenden **keine hartkodierten Farben** mehr, sondern die Material-
  System-Variablen des cyan/orange-Themes.
- App-Shell nutzt `mat-toolbar`; Karten/Buttons/Formulare nutzen Material-Komponenten.
- Lade-/Leer-/Fehlerzustände sind sichtbar und einheitlich gestaltet.
- Layout ist auf schmalen Breiten benutzbar (responsive).
- `npm run build` + `npm run lint` laufen fehlerfrei.
