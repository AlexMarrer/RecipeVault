# Acceptance Criteria – Phase 19

- Auswahl einer Zutat mit hinterlegter `defaultUnit` füllt das leere Einheit-Feld der Zeile
  automatisch mit dieser Einheit.
- Hat der Nutzer in der Zeile bereits eine Einheit eingetippt, bleibt diese bei einem
  Zutat-Wechsel erhalten (kein Überschreiben).
- Zutaten ohne `defaultUnit` lassen das Einheit-Feld unverändert (leer).
- Build + Lint laufen grün.
